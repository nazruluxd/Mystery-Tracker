## ✨ বৈশিষ্ট্য

### 🎯 মূল ফিচার
- ✅ **সহজ ট্র্যাকিং** - রহস্য যোগ করুন এবং ট্র্যাক করুন
- ✅ **স্ট্যাটাস ম্যানেজমেন্ট** - অমীমাংসিত, পেন্ডিং, সমাধিত
- ✅ **অগ্রাধিকার সিস্টেম** - জরুরি, মাঝারি, কম
- ✅ **উন্নত খোঁজা** - দ্রুত খুঁজে পান যা খুঁজছেন
- ✅ **স্মার্ট ফিল্টারিং** - বিভিন্ন মাপকাঠি অনুযায়ী সাজান
- ✅ **মন্তব্য সিস্টেম** - প্রতিটি রহস্যে নোট যোগ করুন
- ✅ **সমাধান রেকর্ডিং** - উত্তর পেলে সেভ করুন

## 🚀 দ্রুত শুরু

### প্রয়োজনীয় সফটওয়্যার
- [Node.js](https://nodejs.org/) (v14 বা উপরে)
- [Git](https://git-scm.com/)

### ইনস্টলেশন

1. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/আপনার-ইউজারনেম/mystery-tracker.git
cd mystery-tracker
```

2. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

3. ডেভেলপমেন্ট সার্ভার চালান
```bash
npm run dev
```

4. আপনার ব্রাউজার খুলুন এবং যান
```
http://localhost:5173
```

## 📦 বিল্ড করুন

প্রোডাকশনের জন্য বিল্ড করতে:

```bash
npm run build
```

বিল্ড প্রিভিউ করতে:

```bash
npm run preview
```
